# ML projects and practical learning

Scope: `/app/strategies`, `/app/marketplace`, `/app/learn` and their new child routes. Operate mode for projects, publishing and missions; Read mode for learning explanations. Inherit the existing institutional light visual system and dashboard shell.

Audience: Spanish-speaking students and researchers preparing CSV predictions for an ML tournament. The immediate job is to register a hypothesis/version, submit through the existing tournament, or choose one learning exercise.

First viewport: a clear task heading, short context, shared research/learning navigation and the next usable action. No advertising hero, invented community activity or performance claims. Flat record lists and readable native forms continue the established product world.

Signature interaction: sliders explain how prediction bias changes MAE and how four round errors change the weekly score; every number in that tool is explicitly illustrative. Mission feedback and saved progress are server computed. The error lab is gated by whole-week release on the server.

Important states: loading versus failure, private versus reviewed publications, selected submission versus declared model version, historical trading tools versus current ML projects. Mobile forms stack and wide research tables scroll inside their own container.

Quality bar: visible labels, 44px controls, keyboard focus, readable research details, honest metrics/provenance and navigable legacy tools. The approved work extends the current identity rather than introducing a new visual world.
