# Inferencia: ¿tu ganancia es real o suerte? (p-valor)

> La estrategia promedia +0,81% diario en 50 días. ¿Habilidad o racha? El estadístico t = 3,15 dice que ver algo así por puro azar pasaría solo 2 de cada 1000 veces (p = 0,002). Con p bajo, la suerte queda descartada como explicación.

## Objetivo

Aplicar un test t de media a 50 retornos diarios (`c3_l8.csv`): calcular el estadístico t y el p-valor bilateral, y decidir con nivel 5% si el retorno promedio es estadísticamente distinto de cero.

## TL;DR

Media diaria +0,0081, error estándar que deja t = 3,15 con n = 50, p-valor 0,002 bilateral. Como 0,002 < 0,05, se rechaza la hipótesis de "todo fue suerte". Ojo: significativo no es rentable (falta restar costos) ni permanente (el mercado cambia).

## 1. La pregunta y el t

Hipótesis nula: la media real es cero y lo visto es ruido. El estadístico t mide cuántos errores estándar está tu media del cero: media 0,0081 entre error estándar ≈ 0,0026, igual a 3,15. Más de 2 ya huele a real; más de 3, a muy real.

```python
t = r.mean() / (r.std(ddof=1) / (len(r) ** 0.5))   # 3,15
```

El t traduce "gané tanto" a "y es tantas veces el ruido": compara estrategias en el mismo idioma.

## 2. El p-valor sin miedo

El p-valor es la probabilidad de ver un t tan extremo si la nula fuera cierta: aquí 0,002, o sea 0,2%. NO es "la probabilidad de que la estrategia funcione"; es "qué tan raro sería este resultado si todo fuera suerte". Tan raro que no cuela.

```python
p = 2 * (1 - Phi(abs(t)))   # 0,002 bilateral
```

Nivel 5%: p < 0,05 rechaza la suerte. El 0,002 la rechaza con margen de sobra.

## 3. Lo que el p-valor no dice

Significativo no significa rentable: con costos y deslizamiento, una media significativa puede volverse pérdida neta. Tampoco significa eterno: 50 días no blindan contra cambios de régimen. Y si probaste 20 variantes y reportas solo la ganadora, tu p real es mucho peor (comparaciones múltiples: otro primo del overfitting de la lección 7).

## Error común

Leer p = 0,002 como "99,8% de probabilidad de que funcione". No: es la rareza del dato bajo suerte, no la probabilidad de que la estrategia sea buena. Y un p alto (0,40) no prueba que no sirva, solo que con estos datos no puedes distinguirla del ruido.
