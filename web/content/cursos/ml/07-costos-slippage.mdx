# Costos: 2 bps + slippage

> El backtest bruto es marketing; el neto es contabilidad. Un edge de 55% de aciertos con rotación frenética puede terminar pagando la fiesta del bróker.

## Objetivo

Modelar costos realistas (2 bps de comisión + slippage proporcional al rango), comparar P&L bruto contra neto y usar un umbral de señal para recortar la rotación que devora el edge.

## TL;DR

- Costo por trade = 2 bps + slippage (≈ ¼ del rango de la barra).
- El costo se paga solo cuando cambias de posición (turnover), no por barra.
- Manda el Sharpe neto: un filtro por umbral suele ganar operando menos.

## 1. El costo vive en la rotación

Cada cambio de posición paga comisión (0,0002) más cruzar el spread, que aproximamos como un cuarto del rango high-low relativo. La fórmula es honesta: si no te mueves, no pagas.

```python
COMISION = 0.0002  # 2 bps
df["slip"] = 0.25 * (df["high"] - df["low"]) / df["close"]
turnover = np.abs(np.diff(np.r_[0, pos])) / 2  # 1 solo si cambias de lado
costo = turnover * (COMISION + df["slip"].values)
pnl_neto = pos * fwd_ret - costo
```

En el notebook verás el puente completo: bruto atractivo, neto decepcionante. Esa brecha es el impuesto por hiperactividad.

## 2. Bruto vs neto: el puente que duele

Con la señal de momentum cruda el hit-rate ronda el 55%, pero el turnover diario hace que el costo acumulado se coma el margen. Reporta siempre los tres números juntos: Sharpe bruto, Sharpe neto y número de trades. Un Sharpe que cae más de la mitad al netear es una estrategia que opera demasiado.

```python
def sharpe(x):
    return float(x.mean() / x.std() * np.sqrt(252)) if x.std() > 0 else 0.0
print(f"bruto={sharpe(pnl_bruto):.3f}  neto={sharpe(pnl_neto):.3f}  trades={int(turnover.sum())}")
```

## 3. Umbral: opera menos, quédate más

Filtrar por convicción (|mom5| > 0,006) elimina los giros débiles donde el costo supera al edge esperado. El bruto baja un poco, la rotación se desploma y el neto sube: menos fiesta, más ganancia.

```python
UMBRAL = 0.006  # deadband: solo un giro fuerte cambia la posición
pos_f = np.zeros_like(pos); pos_f[0] = pos[0]
for t in range(1, len(mom)):
    pos_f[t] = np.sign(mom[t]) if abs(mom[t]) > UMBRAL else pos_f[t-1]
```

Regla de oro: si tu edge por trade es menor que tu costo por trade, no tienes estrategia, tienes una donación al mercado.

## Error típico

Restar un costo fijo por barra en vez de por rotación, o ignorar el slippage porque "son solo 2 bps": con turnover diario, esos polvos traen estos lodos. Costo siempre atado al cambio de posición.
