# Stacking con OOF

> Dos modelos mediocres que se equivocan en cosas distintas valen más que un genio que siempre falla igual. La clave es combinarlos sin hacer trampa.

## Objetivo

Combinar un Ridge con un boosting mediante stacking con predicciones out-of-fold (OOF), entrenar el meta-modelo sin leakage y decidir con accuracy OOS si el ensemble paga.

## TL;DR

- Stacking = bases que predicen + meta que aprende a combinarlas.
- OOF = cada tramo lo predice un modelo que NO lo vio entrenando: sin esto hay leakage.
- Si el stack no supera a la mejor base en OOS, quédate con lo simple.

## 1. Bases que se equivocan distinto

Ridge es lineal y estable; el boosting (HistGradientBoosting si no hay LightGBM) caza no-linealidades pero es nervioso. Esa diversidad es el combustible del stacking: si ambos fallaran igual, combinarlos no sumaría nada.

```python
from sklearn.linear_model import RidgeClassifier
from sklearn.ensemble import HistGradientBoostingClassifier
base_a = RidgeClassifier()
base_b = HistGradientBoostingClassifier(max_iter=100)
```

En el notebook verás que cada base gana en tramos distintos del holdout. Esa es la señal de que combinar tiene sentido.

## 2. OOF: el meta no debe ver el sobreajuste

El error clásico es entrenar el meta con predicciones in-sample de las bases: como ya memorizaron el train, el meta aprende a confiar en su memoria, no en su criterio. La cura es KFold: parte el train en 5, predice cada tramo con un modelo entrenado en los otros 4 y apila esas predicciones OOF como features del meta.

```python
from sklearn.model_selection import KFold
from sklearn.linear_model import LogisticRegression
kf = KFold(n_splits=5, shuffle=False)  # sin shuffle: respeta el orden temporal
oof = np.zeros((len(X_tr), 2))
for tr, va in kf.split(X_tr):
    for j, base in enumerate([base_a, base_b]):
        base.fit(X_tr[tr], y_tr[tr])
        oof[va, j] = base.predict(X_tr[va])
meta = LogisticRegression().fit(oof, y_tr)
```

Sin shuffle porque son series temporales: mezclar rompería la causalidad que cuidaste desde la L2.

## 3. Veredicto en OOS

Bases reentrenadas en todo el train, meta congelado, y accuracy en el 30% final que nadie vio. Reporta base A, base B y stack lado a lado: el stack suele empatar con la mejor base y con menos varianza entre tramos. Empatar siendo más estable también es ganar.

```python
acc = lambda yt, yp: (yt == yp).mean()
print(f"Ridge={acc:.3f}  GBM={acc:.3f}  STACK={acc:.3f}")
```

## Error típico

Meta entrenado con predicciones in-sample, o KFold con shuffle en datos temporales: ambos son leakage y el stack se ve genial en train y plano en OOS. OOF ordenado y holdout final intacto.
