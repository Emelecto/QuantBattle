# Deployment: predict_demo.py

> Un modelo que solo vive en tu notebook es un experimento; uno que predice desde un script con validación es un sistema. El puente entre ambos cabe en 60 líneas.

## Objetivo

Empaquetar el modelo en `predict_demo.py`: validar el esquema de entrada con falla cerrada, reutilizar el mismo featurizador del entrenamiento y emitir la predicción como JSON consumible.

## TL;DR

- Falla cerrada: mejor no operar que predecir con datos corruptos.
- Mismo código de features en train y en serving: evita el skew train-serve.
- La demo reentrena por simplicidad; en producción se sirve el artefacto versionado.

## 1. Valida antes de predecir

El script exige las columnas `dia,close,high,low,volumen`, un mínimo de 30 filas y cero nulos en OHLCV. Cualquier violación emite `{"ok": false, "error": ...}` y sale con código 2: sin señal y con alerta, nunca con una predicción inventada.

```python
if faltantes:
    fail(f"columnas faltantes: {faltantes}")  # sys.exit(2), sin predicción
```

Pruébalo en el notebook rompiendo el CSV a propósito: esa es la prueba más barata de todo el curso.

## 2. Un solo featurizador, dos usos

El skew train-serve aparece cuando producción calcula los lags distinto que el entrenamiento y el modelo ve un mundo que nunca aprendió. La defensa es estructural: `featurizar()` vive en el script y es la única que existe.

```python
def featurizar(df):
    df["ret"] = df["close"].pct_change()
    df["rango"] = (df["high"] - df["low"]) / df["close"]
    for k in (1, 2, 3, 5):
        df[f"lag_{k}"] = df["ret"].shift(k)
    df["mom5"] = df["close"] / df["close"].shift(5) - 1
    return df.dropna().reset_index(drop=True)
```

## 3. De la demo a producción

Ejecuta y consume el JSON desde cualquier sistema: `python predict_demo.py --input ../data/c5_l8.csv` responde `{"ok": true, "pred": 1, "mom5": ..., "filas": ...}`. En producción real el único cambio es serio: el modelo llega serializado y versionado (pickle/onnx + hash), no reentrenado al vuelo; el featurizador y la validación quedan intactos.

```bash
python predict_demo.py --input ../data/c5_l8.csv
# {"ok": true, "pred": 1, "mom5": 0.008421, "filas": 44}
```
